# Mongolian Au Pair

Au Pair зуучлалын веб апп — React + Vite + Express.

Герман, Франц, Австри, Швейцарь, Бельги, Нидерланд, Дани улс руу элсэлт авна.

## Local

```bash
npm install
npm run dev
```

- Web: http://localhost:5173  
- API: http://localhost:3001  

## Production

```bash
npm install
npm run build
npm start
```

Repo: https://github.com/mxnkbatr/aupair
